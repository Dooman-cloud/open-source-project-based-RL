# RISKDOC 사용자 가이드

> **대상**: 서비스 이용자(개인 투자자) | **서비스명**: RISKDOC

---

## 1. 서비스 소개

RISKDOC는 **통계 모델(GJR-GARCH)** 로 주가 변동성과 **VaR(최대 예상 손실)·ES(꼬리 평균 손실)** 을 계산하고, 차트·AI 리포트·챗봇으로 쉽게 이해할 수 있게 보여주는 **금융 리스크 관리 보조 도구**입니다.

### 1.1 핵심 가치

- Black-box AI 예측 대신 **해석 가능한 통계 모델** 사용
- 투자금 기준 **원화 손실액** 표시
- 10개 종목 **손실 고위험 TOP 3** 한눈에 비교
- Gemini AI가 수치를 **일반어로 설명** (매수·매도 지시는 하지 않음)

### 1.2 면책

본 서비스는 **의사결정 보조 도구**이며 투자 손실 책임은 이용자 본인에게 있습니다. 모든 수치는 과거 데이터·모형 기반 **추정치**이며 미래를 보장하지 않습니다.

## 2. 빠른 시작

1. 브라우저에서 **[http://localhost:8501](http://localhost:8501)** 접속 (또는 배포 URL)
2. 왼쪽 사이드바에서 **종목** 선택
3. **신뢰수준**(예: 99%)·**분석 기간**(예: 6개월)·**투자금** 입력
4. 상단 **4개 메트릭 카드**와 **AI 리포트** 확인
5. 차트·랭킹·챗봇으로 추가 질문

로그인은 **필요 없습니다**.

| 설정        | 설명                    | 기본값      |

**신뢰수준 가이드**

- **높을수록 보수적** (99% → 100일 중 약 1일은 예측 손실 초과 가능)
- 안정적 성향: 99% 이상 권장
- 공격적 성향: 95% 전후도 선택 가능

캡션: *"99% 신뢰수준은 투자 손실액이 예측치를 초과할 확률이 1%임을 의미합니다."*

### 3.2 상단 메트릭 카드


| 카드               | 의미                            |
| ---------------- | ----------------------------- |
| **조정 종가**        | 최근 종가 (국내: KRW, 해외·지수: USD)   |
| **최대 손실액(VaR)**  | 다음 거래일 예측 최대 손실 **비율** (음수 %) |
| **최대 평균 손실(ES)** | VaR을 넘는 최악 상황의 **평균 손실 비율**   |
| **예측 변동성(σ)**    | GARCH가 예측한 일별 변동성 %           |


제목 아래 **날짜·장 상태** 안내(예: 장마감, 주말 휴장)가 표시됩니다.

## 4. 기능별 이용 안내

### 4.1 AI 리포트 요약

자연어로 VaR·ES를 **투자금 기준 원화**로 요약합니다.

예: *"신뢰수준 99% 기준 일별 VaR은 3.20%로, 투자금 1000만원 기준 최대 손실 예상액은 약 32.0만원입니다."*

**세부 기술적 지표 분석** (불릿 3종):


| 지표        | 제공 정보                     |
| --------- | ------------------------- |
| RSI       | 수치 + 과매수/과매도/중립 + 해석 문구   |
| 볼린저 밴드    | 위치 신호 + 해석 문구             |
| GARCH 변동성 | 최근 5일 평균 대비 오늘 예측 변동성 변화율 |


### 4.2 차트

**① 주가 + VaR** — 파란선: 종가, 빨간 점선: VaR 하방 수준. 간격이 넓을수록 리스크 큼.

**② 변동성** — 일별 σ 추이, 점선: 기간 평균.

**③ 기술 지표** (3단)

- 상: 종가 + SMA20/60 + 볼린저 밴드
- 중: RSI (70/30 기준선)
- 하: 거래량

차트는 마우스 호버로 수치 확인, 확대·이동 가능(Plotly).

### 4.3 손실 고위험 종목 TOP 3

전체 10종목 중 **예측 VaR 손실액(원)** 이 큰 순서 상위 3개.


| 테두리 색 | 의미                                |
| ----- | --------------------------------- |
| 빨강    | 고위험 (변동성 변화율 10% 초과 또는 VaR 3% 초과) |
| 노랑    | 중간 위험                             |


표시: 순위, 종목명, 예측 변동성 변화율, 예측 VaR 손실액(원).

### 4.4 AI 챗봇

**금융 리스크 분석 전문 AI 어시스턴트** — 종목·설정 변경 시 현재 분석 요약과 함께 환영 메시지가 표시됩니다.

**질문 예시**

- "VaR 15%면 투자금 1000만 원 기준 얼마나 잃을 수 있어?"
- "RSI 77이면 어떤 상태야?"
- "볼린저 밴드 상단 돌파가 무슨 뜻이야?"
- "오늘 리스크가 높은 이유가 뭐야?"

**챗봇이 하는 일**: 수치 기반 리스크 **해석·설명**  
**하지 않는 일**: "매수/매도하세요" 같은 **투자 지시**

답변 말미에 면책 문구가 포함됩니다. API 키 미설정 시 연결 오류 메시지가 표시됩니다.

## 5. 핵심 지표 해석

### 5.1 VaR (Value at Risk)

> 정상 시장에서, 설정한 신뢰수준 안에서 **하루에 넘지 않을 것으로 보는 최대 손실**.

예: 99% VaR = **-3%**, 투자금 1,000만 원  
→ 약 100일 중 1일은 3% 이상 손실 가능, 기준 손실 약 **30만 원**

### 5.2 ES (Expected Shortfall)

> VaR보다 **더 나쁜** 상황이 왔을 때의 **평균 손실**. VaR보다 보수적.

예: ES -5% → 최악 1% 구간에서 평균 5% 손실 수준.

### 5.3 예측 변동성 (σ)

GARCH가 **다음 거래일**에 예측한 변동성. 높을수록 가격 급등락·리스크 가능성이 큼.

### 5.4 RSI (14일)


| 구간    | 상태          |
| ----- | ----------- |
| 70 이상 | 과매수 (하락 경계) |
| 30 이하 | 과매도 (상승 기대) |
| 그 외   | 중립          |


### 5.5 볼린저 밴드 (20일, 2σ)

- 상단 돌파 → 단기 과열·고점 주의
- 하단 이탈 → 단기 과매도·저점 주의
- 밴드 폭 확대 → 변동성 증가 신호

## 8. 자주 묻는 질문

**Q. 이 서비스로 매매 타이밍을 잡아도 되나요?**  
A. 아닙니다. 리스크 **인지·점검**용이며 매매 신호가 아닙니다.

**Q. VaR과 ES 중 무엇을 봐야 하나요?**  
A. VaR은 "일반적 최악 한도", ES는 "그보다 더 나쁠 때 평균". 둘 다 보면 꼬리 리스크 파악에 도움이 됩니다.

**Q. 신뢰수준을 바꾸면 손실액이 왜 달라지나요?**  
A. 99%는 95%보다 **더 극단적인** 손실 구간을 보므로 VaR 절대값이 커지는 것이 일반적입니다.

**Q. 챗봇 대화가 사라졌어요**  
A. 종목·기간·신뢰수준·투자금을 바꾸면 **의도적으로** 대화가 초기화됩니다.

**Q. 해외 주식 가격 통화는?**  
A. USD로 표시됩니다. VaR 손실액(원)은 사이드바 투자금(원) 기준입니다.
